# 覆盖矩阵模板（10 个功能域）

> 用法：按被测系统**实际功能**增删，不要照抄。每域 3-8 条，**必须含边界与安全**。

## 通用 10 域

### A. 登录与会话
| 用例 | 类型 | 验证点 |
|---|---|---|
| 正确凭据进入主界面 | 正常 | 跳转到预期落点 |
| 各角色账号均可登录 | 正常 | 分别验证 |
| 错误密码被拒 | 异常 | 留在登录页 + 有提示 |
| 账号不存在 | 异常 | 同上 |
| **空账号 / 空密码** | 边界 | 表单校验拦住 |
| **超长输入**（200+ 字符） | 边界 | 不 500 |
| **SQL 注入式账号** | 安全 | **不得登录成功** |
| 登出后受保护页不可访问 | 安全 | 服务端会话真失效 |

### B. 权限与角色
| 用例 | 类型 | 验证点 |
|---|---|---|
| 各角色可见功能入口数 | 正常 | 高权限 > 低权限 |
| 界面入口与权限接口一致 | 一致性 | **双源交叉验证** |
| 高权限角色可跨范围切换 | 正常 | 选择生效 |
| 低权限角色范围被锁定 | 正常 | 显示范围且不可改 |
| **低权限角色无越级入口** | 安全 | 高级功能一个都不出现 |

### C. 数据范围校验（**权限系统必有**）
| 用例 | 类型 | 验证点 |
|---|---|---|
| 请求**范围内**数据 | 正常 | 通过 |
| 请求**范围外**数据 | 安全 | **拒绝** |
| 请求**不存在**的对象 | 边界 | 拒绝 |
| 请求**空**参数 | 边界 | 不崩 |
| 拒绝时**提示可见范围** | 可用性 | 用户知道能看什么 |
| **越权请求不产出任何数据/产物** | 安全 | **反向断言**（关键） |
| **拒绝不可被对话内容放宽** | 安全 | 用户"口头确认"也无效 |

### D. 核心业务（问答 / 生成 / 计算）
| 用例 | 类型 | 验证点 |
|---|---|---|
| 正常请求返回业务真值 | 正常 | 与权威来源一致 |
| **低权限账号只看到范围内结果** | 安全 | 范围过滤生效 |
| 高权限账号看到全量 | 正常 | 数量显著多于低权限 |
| 越级请求被说明无权 | 边界 | 不越权 |
| **空输入不发送** | 边界 | 不产生请求 |
| **超长输入** | 边界 | 不崩 |

### E. 长任务（生成 / 导出）
| 用例 | 类型 | 验证点 |
|---|---|---|
| 任务面板出现 | 正常 | 面板可见 |
| **标题/章节正确** | 正常 | 与后端定义一致 |
| 生成中状态可识别 | 正常 | 停止按钮出现 |
| 可中断 | 可用性 | 停止生效 |
| **未越权产出** | 安全 | 任务 0 项完成 |

### F. 会话管理
| 用例 | 类型 | 验证点 |
|---|---|---|
| 新建 / 切换 / 删除 / 重命名 | 正常 | **界面 + 服务端双验证** |
| 历史持久化（刷新后仍在） | 正常 | 回读成功 |
| **跨账号会话隔离** | 安全 | 三层：列表 / 直链 / 接口 |

### G. 文件与产物
| 用例 | 类型 | 验证点 |
|---|---|---|
| 列表结构正常 | 正常 | 含空列表分支 |
| **他人文件不可读** | 安全 | 404 |
| **跨租户产物被拒** | 安全 | 用真实外部 ID 验证 |
| 不存在的 ID | 边界 | 友好 404，**不 500** |
| 未带凭据 | 安全 | 401 |
| **任一用户列表接口不 500** | 回归 | 见"漏 eager-load"类缺陷 |

### H. 界面交互与健壮性
| 用例 | 类型 | 验证点 |
|---|---|---|
| 已删除控件**不回归** | 回归 | 测试设施不得留在生产界面 |
| 折叠 / 展开 | 正常 | 状态切换 |
| 回车发送 / 发送后清空 | 正常 | 输入框行为 |
| 快捷入口灌入预设文案 | 正常 | 非空 |
| 刷新保持登录 | 正常 | 不掉登录 |

### I. 边界与健壮性
| 用例 | 类型 | 验证点 |
|---|---|---|
| 空 / 超长 / 纯符号 / emoji | 边界 | 不崩、不 500 |
| **XSS 载荷不执行** | 安全 | 注册 dialog 监听 + DOM 检查 |
| 接口契约稳定 | 契约 | 键集合 / 类型 / 取值域 |
| **伪造范围参数不放大权限** | 安全 | 6 种取值全部拒绝 |
| 多轮对话保持上下文 | 边界 | 结构层 + **语义层** |
| 刷新保持状态 | 正常 | |

### J. 安全补充
| 用例 | 类型 | 验证点 |
|---|---|---|
| 未登录访问受保护页 | 安全 | 重定向 |
| 未登录调接口（多端点） | 安全 | 全 401 |
| **伪造 token（多形态）** | 安全 | 含"格式合法但不存在" |
| 空 / 畸形凭据 | 安全 | 401 |
| **越权请求（真实链路）** | 安全 | 拒绝 + **无载荷** |
| **权限点门生效** | 安全 | 接口层 + **运行期日志** |
| **多入口绕过回归** | 安全 | 结构断言 + 端到端拒绝 |
| 归属隔离 | 安全 | 他人资源不可读 |
| **口头确认不能放宽范围** | 安全 | 逐字复刻引导话术 |

---

## 裁剪原则

- **小项目**：A/B/C/D + I/J（安全必须有）
- **有权限体系**：C 与 J 是重点（权限收口是验收核心）
- **有长任务**：E 必须（手工测最痛苦的部分）
- **有文件**：G 必须（越权读取是高频漏洞）

## 每条用例的三要素

写用例时明确：**做什么 → 期望什么 → 怎么判定**。
"怎么判定"必须是**客观信号**（HTTP 状态 / 载荷字段 / 日志 / 产物文件），
不能只有界面文字。
